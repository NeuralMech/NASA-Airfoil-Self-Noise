NASA Airfoil Self-Noise Analysis
- NASA Airfoil Self-Noise Dataset을 이용해 익형 자체 소음(SSPL)을 분석한 개인 프로젝트입니다.
주파수 대역별 스펙트럼 해석과 회귀 모델 비교를 하나의 노트북에 정리했습니다.

Note
- f는 설계변수보다는 스펙트럼 축으로 해석했습니다. 

Future Works
